Welcome to the unofficial Odoo Cookbook! This repository was created to help developers and technical consultants find the correct syntax for common operations without having to dig through Odoo's source code for hours.

All snippets are ready to **copy-paste**, focus on modern Odoo versions, and follow the Odoo Community Association (OCA) best practices.

## How to use this Cookbook

Navigate through the sections using the top menu or the sidebar. The repository is structured by architectural layers to help you quickly find what you need:

* **1. ORM & Models:** Computed fields, constraints, CRUD overrides, and recordset operations.
* **2. Views & UI (XML):** Safe form inheritance, dynamic lists, search filters, and Kanban boards.
* **3. Chatter & Mail:** Activity tracking, silent logging, and dispatching template-based emails.
* **4. Wizards:** Transient models for mass updates and step-by-step modal interactions.
* **5. Actions & Cron:** Scheduled background jobs, server actions, and automated triggers.
* **6. OWL & Frontend:** Modern JavaScript UI, custom field widgets, and component patching (hooks & lifecycle).
* **7. Migration & Versions:** Quick reference guides for upgrading code syntax to Odoo 18, 19, and 20.
* **8. Best Practices & Pitfalls:**  Common mistakes (N+1 queries, Expected Singleton, Context pollution) and how to write clean, optimized code.
