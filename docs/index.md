# Odoo Code Snippets & Cookbook 🍳

Welcome to the unofficial Odoo Cookbook! This repository was created to help developers and technical consultants find the correct syntax for common operations without having to dig through Odoo's source code for hours.

All snippets are ready to **copy-paste** and follow the Odoo Community Association (OCA) best practices.

## How to use this Cookbook

Navigate through the sections using the top menu or the sidebar. Each page contains real-world use cases, such as:

* Creating computed fields and interactive wizards.
* Extending XML views without breaking other modules.
* Sending emails and logging notes in the Chatter.

!!! tip "Contribute"
    Do you have a brilliant snippet you use in every project? Open a Pull Request on our GitHub repository to add it!
